## 🚀 Project Overview

The **Super Store Sales Dashboard** is an interactive business intelligence project built in **Microsoft Excel** to transform raw Super Store sales data into meaningful, decision-ready insights.

The dashboard provides a centralized view of **sales performance, transactions, quantity ordered, regional performance, product categories, customer segments, shipping modes, and monthly trends**.

The project focuses on building a dashboard that is not only visually appealing but also **dynamic, interactive, and business-oriented**.

---

## 🎯 Project Objective

The primary objective of this project was to:

* Transform raw sales data into meaningful business insights
* Create an interactive Excel dashboard
* Track important sales KPIs
* Analyze sales across different regions and years
* Identify high-performing cities and categories
* Understand customer segment behavior
* Analyze shipping mode distribution
* Track monthly quantity trends
* Build a reusable and dynamically updating reporting solution

---

## 📌 Dashboard KPIs

The dashboard provides four major performance indicators:

| KPI                   | Description                         |
| --------------------- | ----------------------------------- |
| 💰 **Total Sales**    | Overall sales generated             |
| 📈 **Average Sales**  | Average sales value                 |
| 🧾 **Transactions**   | Total number of transactions/orders |
| 📦 **Total Quantity** | Total quantity of products ordered  |

---

## 📊 Dashboard Analysis

### 1. 🚚 Ship Mode Sales %

Visualizes the percentage contribution of different shipping modes:

* Standard Class
* Second Class
* First Class
* Same Day

This helps understand customer shipping preferences and order fulfillment patterns.

---

### 2. 🌎 Region-wise Transactions

Analyzes transaction distribution across:

* Central
* East
* South
* West

This provides a quick overview of regional sales activity.

---

### 3. 📅 Monthly Quantity Ordered

A monthly trend visualization showing how the quantity ordered changes throughout the year.

This helps identify:

* Seasonal patterns
* High-demand months
* Low-demand periods
* Overall ordering trends

---

### 4. 🏙️ Top 5 Cities by Sales

Identifies the top-performing cities based on sales.

This can help businesses understand:

* High-value markets
* Geographic sales concentration
* Potential expansion opportunities

---

### 5. 🛋️ Category-wise Transactions

Analyzes transactions across major product categories:

* Technology
* Office Supplies
* Furniture

This helps identify which product categories generate the highest transaction volume.

---

### 6. 👥 Consumer Type Quantity Ordered

Analyzes quantity ordered across customer segments:

* Consumer
* Corporate
* Home Office

This provides insight into customer purchasing behavior.
